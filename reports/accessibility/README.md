# Report di accessibilità

Cartella dedicata ai report di accessibilità generati dall'agente
[`accessibility-auditor`](../../agents/accessibility-auditor/README.md).

I report sono file Excel (`.xlsx`) nominati `a11y-report-YYYY-MM-DD.xlsx` e seguono
le **WCAG 2.2** (livello A + AA). Ogni file contiene i fogli `Summary`, `Findings` e
`Coverage`.

Per generarne uno nuovo: chiedi a Claude Code "fai un audit di accessibilità e genera
il report".
